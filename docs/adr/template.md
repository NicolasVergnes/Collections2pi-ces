# ADR NNNN — Titre court

- Date : AAAA-MM-JJ
- Statut : proposé | accepté | remplacé par ADR NNNN
- Tâche : T-nnn, PR #nn

## Contexte
Deux ou trois phrases : quel problème, quelles contraintes (hors ligne, coût < 100 €/mois, UE, mobile).

## Décision
Ce qui est décidé, en une phrase, puis les détails nécessaires pour l'appliquer.

## Options écartées
- Option — pourquoi non.

## Conséquences
Ce que ça rend facile, ce que ça rend difficile, ce qu'il faudra surveiller.

# Backlog — Deux

Format : `- [ ] **T-nnn** (exigences) Titre — critères : … — étiquettes : …`. Étiquettes : `v1` `v2` `v3` `needs-human` `blocked` `data` `ml`. Une tâche cochée cite sa PR. L'ordre est l'ordre de prise. Les identifiants sont stables : une nouvelle tâche prend le plus grand numéro existant + 1 et sa place dans la liste fixe son ordre de prise.
